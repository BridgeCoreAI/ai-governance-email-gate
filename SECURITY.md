# Security and scope

This project is an educational synthetic demonstrator, not a production email security service. Version 0.1.0 is the current development baseline.

Do not use real credentials or confidential data. Human identity, time, classification and attachment hashes are trusted inputs; mutable memory, concurrency and production transport bypass are outside the implemented boundary.

Report ordinary defects through an issue with a minimal synthetic reproduction. For a finding containing sensitive information, use GitHub private vulnerability reporting if enabled, or contact the maintainer through an established private channel before disclosure. Do not publish secrets in an issue.

No production security support or enterprise assurance is claimed.

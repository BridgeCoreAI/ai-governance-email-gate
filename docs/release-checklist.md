# Release checklist

Repository stays private while building. Publication requires Grace Adjeli's explicit decision.

- [ ] Review final source and documentation for scope accuracy.
- [ ] Run all tests on the exact release commit and review CI results.
- [ ] Reproduce demo output and compare source/test hashes.
- [ ] Inspect fixtures, history and evidence for secrets or personal information.
- [ ] Confirm negative-path scenarios and non-execution outcomes.
- [ ] Confirm reviewer/authentication and transport simulations are clearly labeled.
- [ ] Check LICENSE, authorship, and branding.
- [ ] Review public README, architecture, and evidence conclusions.
- [ ] Obtain public-release decision; then change visibility and tag the release.

Episode 6 should describe the implementation and evidence actually present in the reviewed version.
